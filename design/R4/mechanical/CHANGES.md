# SmartVio R4 结构 CAD 修改说明（R3 → R4）

基线：R3 交付包 `engineering/mechanical`（只读，未改）。R4 源码和输出在本目录：

| 文件 | 内容 |
|---|---|
| `build_mechanics.py` | 修改后的 CadQuery 源（结构与写法沿用 R3） |
| `assembly_sequence.py` | 新增：装配顺序 + 扫掠插入干涉检查 |
| `flex_reference.py` | 修改：KEYS6 主板端按 ECO L-09 移 +0.30 mm |
| `R3-to-R4.patch` | 上面 3 个源文件和 `parameters.json` 相对 R3 的 diff（已验证能干净打到 R3 上） |
| `parameters.json` | 构建生成的 R4 尺寸参数 |
| `pcb-interface-eco-R4.json` | 结构对 PCB 提出的开孔/禁布要求（交给 PCB ECO 执行） |
| `assembly-status.json` | 包内原有检查逻辑的输出：逐件 STEP 回读、全成对碰撞、外形包络、字符避让 |
| `assembly-sequence-check.json` | 装配顺序和扫掠干涉检查的结果 |
| `step/` | 新增或改动的制造件 STEP（20 个零件 + 3 种调整垫片 + 零件总装 + 按钮毛坯），共约 13 MB |

**重建方法**：把 3 个 .py 放进 R3 包的 `mechanical/cad/`（或直接打 patch），然后运行
`SMARTVIO_ENG=<包>/engineering python3 cad/build_mechanics.py`。需要 cadquery 2.8.0 和 DejaVu Sans Bold 字体（可用环境变量 `SMARTVIO_FONT` 换成别的字体）。在本环境中一次完整构建约 6 分钟。

## 0. 结论

- 全部零件回读后有效，每个零件都是 1 个实体。3 种调整垫片按设计各由 4 段组成。
- 全成对碰撞检查：62 481 对，其中 1 274 对做了精确布尔运算，**相交 0 处**。
- 装配顺序扫掠检查：14 步，2 139 次 OCC 布尔求交，**全部通过**。5 处有意的弹性卡扣，干涉深度都不超过设计值（见第 2 节）。
- R3 的外形约束全部保持：
  - 上盖 148×49；
  - 非滚轮外突 3.85，限值 5；
  - 下杯 77×45，伸入 20.90，腔体为 78×47×22；
  - 总高 **24.75**，比 R3 的 24.90 降低 0.15，限值 25。
- 13 处雕刻字符四周 0.3 mm 内都是实体，不碰任何孔、缺口或沉台。

## 2. 装配顺序（已扫掠验证）

**上盖分装**：上盖屋顶朝下放在台面上，零件沿世界 +Z 方向装入。

| 步骤 | 内容 |
|---|---|
| C1 | 5 个按键从内侧装入：Ø5.0 键杆穿过 Ø5.2 孔，Ø6.2 法兰进入沉槽 |
| C2 | 3 根导光柱从内侧装入，法兰顶住屋顶 |
| C3 | 扬声器放入屋顶的扬声器腔，边框贴住腔顶 |
| C4 | 控制板（盖板）装入，2 根销定位，压住扬声器弹片 |
| C5 | 贴 PET 背垫：按键 1–2 下方一片，扬声器下方一片 |
| C6 | 按键背撑架，用 2 颗 M1.6 自攻钉固定，同时压紧控制板 |
| C7 | USB 板装到 4 根屋顶柱上，J401 进入收紧后的屋顶开口 |
| C8 | USB 托架，用 3 颗 M1.6 自攻钉固定；第 4 根柱只压不锁 |
| C10 | 音频板连同 4 个插座装入，插座肩面顶住屋顶压台 |
| C11 | 音频框卡入：南侧 2 处卡在刀片唇上（弹性 0.35），北侧挂在背撑架托边（0.30）和 USB 托架轨上（0.35） |

**下杯分装**：下杯开口朝上，零件沿 −Z 方向装入。

| 步骤 | 内容 |
|---|---|
| L1 | 底膜、NTC 隔片、RT1921 |
| L2 | 电池 |
| L3 | 顶部泡棉、顶隔片 |
| L4 | 主板压过 4 个卡齿（弹性 0.45） |
| L5 | 主板与音频板之间的绝缘膜 |

**合装**：

| 步骤 | 内容 |
|---|---|
| F1 | 先焊好 FPC 并折好，接上同轴，再把下杯分装沿 +Z 推入上盖，4 个零间隙卡扣卡合（弹性 0.25） |
| F2 | 把整机放入琴腔，用 4 颗木螺钉固定。下杯离腔壁 0.5 |

**检查方法**：每个零件（或整块板连同元件）从装配位置外 10–30 mm 处出发，沿装入方向移到最终位置。扫过的体积取三部分的并集：

- 起点位置的实体；
- 终点位置的实体；
- 每个不平行于运动方向的面沿运动方向拉出的棱柱。

再与已装的每个实体做 OCC `BRepAlgoAPI_Common`，公共体积大于 1e-4 mm³ 判为干涉。

- 退化成零体积的棱柱跳过，例如 B 样条侧壁。
- 弹性卡扣逐个列出，只有干涉深度不超过设计搭接量时才判通过。
- FPC 和同轴线是柔性件，不做扫掠，只在最终位置参加全成对碰撞检查。
- 检查上盖时不带 0.15 mm 的顶面雕字。顶面雕字离所有开口都 ≥0.3，已单独检查。

## 4. 滚轮露出量（Q3）的说明

板子叠层固定了滚轮的高度：盖板 PCB 顶面 z 0.5，RK10J 本体 1.5，滚轮 Ø14、厚 1.0，所以轮顶在 z 3.0，比盖顶 3.8 **低 0.8**。要让轮缘高出盖顶约 1.5，就得把滚轮抬高 2.3 mm，只有三种办法，都不可行：

- 加旋钮帽：Q3 明确不要；
- 抬高盖板 PCB：所有非轮件都会超过 5 mm；
- 换电位器型号：属于电气范围。

**R4 的做法是降低滚轮周围的盖面**：

- 每个滚轮在北边缘开一个 12 mm 宽的拇指缺口，缺口底面在 z 1.5（下面补了 0.9 厚的实体底台）。
- 这样滚花轮缘高出局部盖面 **1.5 mm**，北侧大约 100° 的弧段完全露出。拇指从模块的长边沿琴身方向拨动即可。
- 开孔保持 Ø15.2，轮缘到孔壁 0.5。

量产时如果允许“滚轮露出盖顶”，可以考虑换带延伸轮或更高轮的型号。
