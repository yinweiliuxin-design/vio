## 定稿要点

| 方面 | 定稿 |
|---|---|
| 外形与安装 | 148 × 49 mm（含外壳，≤ 150 × 50），齐平嵌入琴背，距琴尾 110–258 mm；只有旋钮高出约 7 mm |
| 琴体加工 | 琴厂 CNC 三级台阶槽：扬声器段 11 / 功能区 17 / 电池段 14 mm 深；琴身 25 mm，功能区下方余约 8 mm；中央梁 60–65 mm 宽，槽两侧各余 5 mm 以上 |
| 分区（从琴头端） | 扬声器 34 mm（距琴尾 224–258）/ 功能区 70 mm（154–224）/ 电池 + USB-C 44 mm（110–154）；琴码中心距琴尾 155 mm |
| 面板 | 左扬声器；中段上排 3 个编码器旋钮（靠 G 弦）、中排 4 个插孔（PHONES、AUX、LINE、SEND）、下排 5 个按键（PWR、BT、MODE、FX、MIX）和 3 颗灯；右端 USB-C |
| 主控 | ESP32-S3（外接天线模组），I2S0 接编解码器，I2S1 送外放和蓝牙；USB-C 升级固件 |
| 音频 | 一颗编解码器：左路 ADC 采拾音器，右路 ADC 采单声道伴奏；伴奏立体声模拟直通耳机和 LINE；外放和蓝牙用 S3 混好的单声道伴奏；SEND 取前置放大的干声 |
| 外放 | 28 mm 扬声器 + MAX98357A，默认最大约 1 W |
| 蓝牙耳机 | 专用蓝牙发射芯片，SBC 按主流配置适配；注明“实时练琴请用有线耳机” |
| 拾音 | 沿用琴上原有单路拾音器；一路 CMOS 输入高阻前置（沿用 R4 的 TLV906x 系列），另一半做 SEND 缓冲 |
| 电池 | 10 × 30 × 40 mm、约 1300 mAh；耳机练琴约 9–10 h；不加电量计，App 按 10% 一档显示 |
| App | 安卓网页版：电量、输出切换、音量音色效果、伴奏比例、调音器、最大音量限制 |
| 成本 | 电子部分约 24–33 美元/台（1000 台量，粗估） |
| 出图前提 | 开发板验证和 1:1 面板模型装琴试拉都达到通过标准 |

## 编解码器芯片要求（①–⑥）

| 编号 | 要求 | 达不到时 |
|---|---|---|
| ① | ≥ 2 路 ADC，48 kHz / 24 bit；每路可编程模拟增益 0 到 ≥ +24 dB；动态范围 ≥ 90 dB | 换芯片 |
| ② | 输入端能把 AUX 左右两路在模拟域相加后送进右路 ADC | 芯片外两只电阻相加 |
| ③ | AUX 输入到耳机输出和 LINE 输出的模拟直通，左右独立，增益可调并可静音 | 加立体声 ADC 专收伴奏，改全数字混音（约 +1 美元） |
| ④ | 立体声 DAC；耳机和 LINE 输出各有混音器，同时混入 DAC 和直通，左右可分别调 | 同 ③ |
| ⑤ | 耳机放大直推 16–32 Ω；LINE 约 1 Vrms；开关机防“噗”声 | 外加耳放 |
| ⑥ | I2C 控制；I2S 从模式 48 kHz；单 3.3 V 供电；QFN ≤ 5 × 5 mm；供货稳定 | 换芯片 |

固件配合：S3 送 DAC 的只有琴声（避免伴奏加两次）；MIX/App 改伴奏比例时同时改直通增益和 S3 内部比例；开关机先静音直通和耳放。
候选：TI TLV320AIC3204；国产可比较 ES8388。验证阶段两款评估板都实测。

## 蓝牙发射芯片要求（⑦）

| 编号 | 要求 |
|---|---|
| ⑦-1 | A2DP Source，必须支持 SBC；支持 AAC 加分 |
| ⑦-2 | I2S 数字音频输入（从模式，48 kHz）；只有模拟输入的方案不选 |
| ⑦-3 | 串口控制：开关、配对、回连、断开、状态上报 |
| ⑦-4 | AVRCP 绝对音量；开机自动回连；记住 ≥ 4 副耳机 |
| ⑦-5 | 关蓝牙时可断电或极低功耗 |
| ⑦-6 | 与 S3 的 BLE 同时工作不互相干扰；有认证过的模组和天线方案 |
| ⑦-7 | 有量产模组和厂家技术支持，供货稳定 |

## 验证通过标准

| 项目 | 标准 |
|---|---|
| 有线耳机延迟 | ≤ 10 ms |
| S3 负载 | 音效 + 混音 + 调音器 + BLE，两核各 ≤ 70%，连续 1 小时不断音 |
| 伴奏路由 | 耳机/LINE 立体声伴奏，外放/蓝牙单声道伴奏；不被加两次；调 MIX 各输出比例一致 |
| 拾音器电平 | 最大力度不削波；正常力度音量够；底噪听不出 |
| 蓝牙兼容 | 5 个品牌主流耳机都能配对和回连，连续 10 分钟无断续 |
| 无线共存 | 同时连 App 和蓝牙耳机，不断音、不掉线 |
| 电流 | 不高于 R4 模拟值 |
| 面板操作 | 拉琴时不误碰；不低头能摸到旋钮和按键；插头插拔顺手；肩托不碰旋钮 |
