# SmartVio R5 电子设计待定问题清单（合作方案附件3）

## 1 说明

- 本清单列出 R5 电子设计中尚未确定、需要乙方给出结论的问题，以及布局规则和固件约束。产品要求以《SmartVio R5 开发合作方案》为准，技术细节见《SmartVio R5 最终方案》。
- 乙方在附件2《电子设计审查与修改报告》第二节逐项答复，结论最终落到原理图、PCB 和固件功能规格书。
- 关闭时间：
  - **阶段 1 结束时**：第 1、6、11、17、20、28 项（与编解码器、蓝牙发射芯片选型有关），是阶段 1 放行条件之一。
  - **阶段 3 原理图评审前**：其余各项，以及第 3 节的 7 条布局规则（合作方案验证项 3-2）。
- 第 26–32 项是为通过 FCC、CE 认证要在电子设计里落实的事项，认证要求见合作方案 2.8 节。
- 标【待核实】的数据来自公开资料或开发工具库，以元件规格书为准。

## 3 布局规则（7 条）

阶段 3 原理图和 PCB 评审时逐条核对（合作方案验证项 3-2）。

1. **音频时钟**（MCLK / BCLK）要短、少过孔，走在紧邻完整地平面的层，和模拟线保持 ≥ 3W 间距。
2. **TPD2S300** 的 VBIAS、VPWR 电容紧贴芯片，否则 CC 口的静电钳位达不到规格书水平。
3. **TPS63070** 功率焊盘的阻焊开窗与钢网一致；开关节点和电感下方不走 NTC、模拟和音频线；其他过孔离开关铜 ≥ 1.5 mm。
4. **BQ24074** 的散热焊盘打过孔。
5. **高阻节点要短**：开关机使能（4.7 MΩ）走线 ≤ 10 mm、远离电感；eFuse 的 ITIMER 电容距引脚 ≤ 1.5 mm；拾音输入（≥ 1 MΩ）加保护环，远离时钟和天线。
6. 所有 IC 封装都有**丝印和 1 脚标记**。
7. **一块完整地平面**，按功能分区布局，不切割；D 类功放和升降压的大电流回路就近闭合，不经过拾音前置和编解码器模拟区。

## 4 保护设计要落实的地方

| 项目 | 要求 |
|---|---|
| USB 过压 / 浪涌 | SMF12A TVS → TPS259470L（过压门限标称 5.90 V，限流 1.34 A）→ BQ24074 |
| USB CC / 数据线 | TPD2S300（CC1 / CC2）、TPD2S703 + USBLC6（D+ / D−）；CC1、CC2 各接 5.1 kΩ 下拉（第 26 项） |
| USB 静电目标 | VBUS 接触放电 ±8 kV；1 m 线热插拔时 VBUS 过冲 < 15 V |
| 音频插座静电 | 4 个 3.5 mm 插座的信号脚都加低电容 ESD 器件，就近放在插座旁 |
| 拾音输入 | 压电拾音器受敲击会产生尖峰电压：串联电阻加对电源钳位，不影响 ≥ 1 MΩ 输入阻抗和底噪 |
| 按键、编码器 | 金属轴和按键外壳接地，或信号线加 ESD；旋钮为塑料 |
| 电池 | 电池包自带保护板（过充、过放、过流、短路），三线带 10 kΩ NTC 接 BQ24074 TS；另有板载 NTC 加 TPS3700，充电温度窗口约 4.8–39.5 °C |
| 充电时间 | BQ24074 快充定时 9.1 h；固件的充电会话上限按 1300 mAh 设定 |

## 5 固件约束

下列各条是硬件设计要给固件留出条件的地方，乙方写进固件功能规格书（合作方案验证项 3-9）。

**音频**

- S3 送给 DAC 的只有琴声；伴奏只经模拟直通到耳机和 LINE，只经 S3 混音到外放和蓝牙。
- MIX 键或 App 改伴奏比例时，同时改编解码器直通增益和 S3 内部比例。
- 开关机、切换输出时先静音直通和耳放；编解码器在时钟稳定后再配置。
- 有线耳机端到端延迟 ≤ 10 ms：I2S DMA 缓冲要小，编解码器 ADC / DAC 数字滤波器的延迟也计入。台架固件默认每块 64 帧 × 3 个 DMA 缓冲，理论缓冲延迟 4.00–5.33 ms（不含编解码器滤波延迟）。
- 音效、混音、调音器和 BLE 同时运行时，两个核的负载各 ≤ 70%。

**电源与充电**

- BQ24074 平时 EN2 / EN1 = 0 / 1（USB500），不用 ILIM 模式（1 / 0），只在 USB 挂起时用 1 / 1。
- 充电会话上限按 1300 mAh 设定（约 5 h）。
- 电压监测：打开测量使能后等 ≥ 100 ms 再采样，采完关掉；出厂对电池和 SYS 电压各做一点校准。
- 插 USB 软关机后，PWR 键低电平 ≥ 50 ms 即清除关机锁存并重启。
- 耳机检测极性可配置，200 ms 去抖。

**无线与升级**

- S3 的 Wi-Fi 不开，只用 BLE。
- 蓝牙关闭时断开蓝牙芯片电源：断电前先停 I2S1，并把接它的 I2S 和 UART 脚设为高阻，避免通过信号脚向断电芯片反灌（硬件侧见第 8 项）。
- 固件升级走 S3 原生 USB（GPIO19 / 20）。固件挂掉时要能进下载模式，所以 GPIO0 要引到测试点或按键。

**认证和安全**（满足 FCC、CE 和欧盟网络安全要求；台架验证固件为了联调方便没有做这些措施，不能直接用于量产）

- BLE 发射功率在固件里固定在第 27 项定下的低档；蓝牙发射模块的发射功率同样设上限。
- BLE 配对加密（LE 安全连接）后才能修改设置；未配对时只允许广播和读电量。
- 固件升级校验签名；量产开启安全启动和 flash 加密，下载口只允许安全下载模式；量产固件关闭调试命令行。
- 密钥归甲方：量产签名私钥由甲方生成和保管，不交给乙方。乙方开发和样机阶段只用测试密钥；量产时乙方交未签名的可烧录文件，甲方签名后交回乙方烧录。flash 加密用芯片首次启动时自行生成的密钥（ESP32-S3 支持，写入 eFuse 后不可读出）。量产烧录和 eFuse 烧写流程（安全启动公钥摘要写入、下载口锁定）由乙方编写，甲方批准后执行。
- USB 诊断口：量产固件保留经 USB-C 的诊断口（S3 原生 USB 的虚拟串口，不另加芯片），分两级：
  - 未认证时只读：固件版本、序列号、电池电压和温度、充电状态、故障记录、出厂测试结果；
  - 改参数、工厂测试命令、清除记录要先用甲方密钥认证（挑战—应答，认证密钥和固件签名密钥分开）；固件升级只接受甲方签名的固件。
  - 出厂测试时把序列号和测试结果写进设备，供以后读取。
  - 命令和数据格式写在《USB 诊断接口文档》里，阶段 3 中期交甲方；甲方据此开发电脑 Chrome 用的 USB 诊断网页。
- 耳机输出有默认最大声压上限，超过时 App 提示（第 30 项）。
- 维护软件物料清单（SBOM），有漏洞处理和安全更新流程（2027-12-11 起欧盟《网络韧性法》要求）。

## 6 接口与管脚预算（供参考）

**接口**

| 接口 | 连接 | 说明 |
|---|---|---|
| I2S0 | S3 ↔ 编解码器，全双工 | MCLK、BCLK、WS、DOUT、DIN；48 kHz；S3 为主，编解码器为从 |
| I2S1 | S3 → MAX98357A + 蓝牙芯片 | 只发送。台架固件默认共用 I2S0 的 BCLK / WS，只多用 1 个 DATA 脚；也可单独出 BCLK / WS（多 2 个脚） |
| I2C | S3 → 编解码器 | 7 位地址：TLV320AIC3204 为 0x18；ES8388 为 0x10（CE 接低）或 0x11（CE 接高） |
| UART | S3 ↔ 蓝牙芯片 | 台架固件默认 115200 bps，以所选模块为准 |
| USB | S3 原生 USB（GPIO19 = D−，GPIO20 = D+） | 固件升级、调试和 USB 诊断；经 TPD2S703 + USBLC6 |
| ADC | 电池和 SYS 分压 | 接 ADC1（GPIO1–10） |
| 脉冲计数 | 3 个编码器 | S3 有 4 个计数单元，够用 |

**管脚预算**【待核实】

ESP32-S3-MINI-1 / 1U 引出 39 个可作 GPIO 的脚：IO0–18、IO21、IO26、IO33–42、IO45–48、TXD0 / RXD0（IO43 / 44）、USB D±（IO19 / 20）。带 PSRAM 的模块版本会占用部分脚，以模块规格书为准。IO0、IO3、IO45、IO46 是启动配置脚，上电时不能被外部电路拉到错误电平。

| 信号组 | 脚数 | 必须直接接 S3？ |
|---|---|---|
| I2S0（MCLK、BCLK、WS、DOUT、DIN） | 5 | 是 |
| I2S1 DATA（共用时钟时） | 1 | 是 |
| I2C | 2 | 是 |
| 蓝牙 UART | 2 | 是 |
| USB D± | 2 | 是（固定） |
| 编码器 A / B × 3 | 6 | 是 |
| 电池、SYS 电压采样 | 2 | 是（ADC1） |
| PWR 键检测、LTC2954 INT 和 KILL | 3 | 是 |
| BT、MODE、FX、MIX 按键 | 4 | 可扩展 |
| 指示灯（单色） | 3 | 可扩展 |
| 插座检测 | 2–4 | 可扩展 |
| MAX98357A SD、蓝牙电源使能、编解码器复位（如有） | 3 | 可扩展 |
| BQ24074：EN1、EN2、CE、PGOOD、CHG | 5 | 可扩展 |
| 电压测量使能 | 1 | 可扩展 |
| 故障输出：eFuse、TPD2S300、TPD2S703 | 3 | 可扩展或线与合并 |
| **合计** | **约 44–46** | 对比可用 39（IO43 / 44 最好留作调试串口） |

可选的办法：用一颗 I2C IO 扩展器接“可扩展”一栏（编解码器已在 I2C 上）；三个故障输出都是开漏时可线与成一个；编码器按压不接。台架固件的接线（WIRING.md）是为开发板排的，不是量产管脚。
