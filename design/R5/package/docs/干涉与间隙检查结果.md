# R5 外壳 V0.3 干涉与间隙检查结果

检查对象：3D 总装（面盖、底壳、旋钮、按键帽、导光柱、主板及元件包络、USB-C 小板、电池、扬声器、螺钉、琴体槽）。

## 干涉

**没有意外干涉。** 只有以下设计上的接触：

- 面盖凸台端面顶住主板和 USB-C 小板；
- 螺钉拧进凸台和木垫；
- 旋钮 D 孔的 3 条压筋压在编码器轴上（每个旋钮约 0.37 mm³，设计过盈）；
- 卡扣舌外面贴住底壳内壁，卡扣钩在卡扣窗里；
- 主板固定螺钉的螺钉头在主板背面元件包络范围内（12.5 mm³ × 4 处，属于正常占位）。

## 最小间隙

| 位置 | 实际 mm | 要求 mm | 结果 |
|---|---|---|---|
| 底壳与琴槽（侧 0.25 / 底 0.3） | 0.25 | ≥ 0.2 | 合格 |
| 面盖与底壳（卡扣贴合） | 0 | 0 | 正常接触 |
| 主板元件与底壳 | 0.55 | ≥ 0.3 | 合格 |
| 主板与底壳 | 0.55 | ≥ 0.3 | 合格 |
| 主板背面包络与壳底 | 1.05 | ≥ 0.5 | 合格 |
| 主板元件与面盖（插座、编码器在孔里） | 0.25 | ≥ 0 | 合格 |
| 电池与底壳 / 限位筋 | 0.2 | ≥ 0 | 合格 |
| 电池顶与面盖（鼓胀余量） | 1.05 | ≥ 1.0 | 合格 |
| 电池与 USB-C 小板 | 2.5 | ≥ 0.5 | 合格 |
| 扬声器与底壳侧壁 | 0.55 | ≥ 0.5 | 合格 |
| USB-C 小板与底壳 | 0.35 | ≥ 0.3 | 合格 |
| USB-C 座与面盖槽 | 0.17 | ≥ 0.05 | 合格 |
| 按键帽触头与轻触开关（静止） | 0.1 | ≥ 0.05 | 合格（公差紧，首样做 3 种触头长度试配） |
| 导光柱底与 LED 顶 | 0.3 | ≥ 0.2 | 合格 |
| 旋钮孔底与轴端 | 0.5 | ≥ 0.3 | 合格 |

注意：

- 以上是按 M-R5-06 的**建议元件尺寸**算的。乙方选定实际元件后要重算。
- 电池按 10.0 mm 厚计算（名义鼓胀余量 1.2 mm，3D 里局部最小 1.05 mm）。成品包厚度到上限 10.3 mm 时余量只剩约 0.75 mm，低于 1.0 mm 的要求：选电池时厚度尽量 ≤ 10.0 mm，做不到请告知甲方加深电池段。
