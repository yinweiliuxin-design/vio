# R5 外壳 V0.2 说明

外壳和琴体加工由甲方负责。本文件夹给乙方的用途有两个：

1. **按图 M-R5-06《主板结构接口图》设计主板**：板外形、4 个安装孔、各面板件的位置和高度限制。图上都是甲方预留的**建议值**，乙方在阶段 3 选定元件后确认或提出修改，甲方据此把外壳定稿。
2. **模块总装**：乙方把主板、USB-C 小板、电池、扬声器装进甲方提供的外壳，步骤见《装配说明》。

## 结构

1. **琴背槽**：先铣一个 2.0 mm 深的台阶，大小 148.4 × 49.4（面盖每边留 0.2 缝）；再往下铣三段深槽 11 / 17 / 15 mm，四角各留一块半径 4.6 mm 的木垫。
2. **面盖**（2.0 厚）压在台阶上，顶面与琴背齐平。4 颗 ST2.2 沉头自攻钉穿过面盖四角，拧进木垫。
3. **底壳**用 8 个卡扣挂在面盖下面，四周离槽壁 0.25，底部离槽底 0.3，不碰琴。
4. **主板和 USB-C 小板**拧在面盖背面的凸台上（主板 4 颗 M2，USB-C 小板 2 颗 M1.6）。插头插拔、按键的力直接传到面盖和台阶，不经过卡扣。
5. 面盖背面两条加强筋（1.2 × 3）；三段弧形筋给扬声器定位；底壳琴头段的隔板把扬声器背后隔成约 5.5 cm³ 的密封腔。
6. **旋钮** Ø13，高出琴背 7.0；**按键帽**高出 0.5；**导光柱**顶面与面盖平。

## 和乙方有关的接口（详见 M-R5-06）

| 项目 | 建议值 |
|---|---|
| 主板 | 外形 ≤ 64.5 × 43（X 36.5–101，y 3–46），厚 1.0；顶面在面盖坐标 Z −12.00；4 个 Ø2.2 安装孔 |
| EC11 编码器 | 本体 ≤ 12 × 12 × 6.5；M7 螺套顶 Z −0.5（不用螺母）；D 轴 Ø6 / 平面 4.5，轴端 Z +5.0（距板顶 17.0） |
| 3.5 mm 插座 | 立式；本体 ≤ Ø9 到 Z −2.3；插口鼻 ≤ Ø6.0，口面 Z −0.2（距板顶 11.8） |
| 轻触开关 | 6 × 6，总高 5.0（按钮顶 Z −7.0） |
| LED | 0603 顶发光，顶 ≤ Z −11.2 |
| 其他顶面元件 | ≤ 9.5（距板顶）；面盖加强筋下方 ≤ 6.5 |
| 背面元件 | ≤ 1.5 |
| USB-C 小板 | X 138.5–145.2，y 14.5–34.5，顶面 Z −9.60；立式 USB-C 口面 Z −0.3（距板顶 9.3） |
| 电池 | 放在 X 106–136，y 4.5–44.5，Z −13.2…−3.2；成品包（含保护板、NTC、出线）≤ 30 × 42 × 10.3 |
| 扬声器 | Ø28 × ≤ 5.5，正面朝面盖网孔 |
| 拾音线 | 经底壳穿线孔（默认 X 99，y 24.5，Ø4）接主板背面的连接器，孔位可按乙方连接器位置改 |

坐标：X 沿琴身，X0 = 模块琴头端；y 横向，y0 = G 弦侧边；Z0 = 琴背面 = 面盖顶面，Z 负值往琴里。

## 还没定的

- 元件实际料号和高度（乙方阶段 3 选型后确认，见《首样前待解决问题清单》第 1 项）。
- 原控制腔尺寸、拾音穿线孔位置、琴背平整度（甲方实测）。
- 面盖材料（甲方决定，见《首样前待解决问题清单》第 2 项）。
- 天线位置（乙方给方案后，外壳预留）。
