## 结构怎么做的

1. **琴背槽**：先铣一个 2.0 mm 深的台阶，大小 148.4 × 49.4（面盖每边留 0.2 缝）；再往下铣三段深槽 11 / 17 / 14 mm，四角各留一块 R4.6 的木垫。
2. **面盖**（POM 黑，2.0 厚）压在台阶上，顶面与琴背齐平。4 颗 ST2.2 沉头自攻钉穿过面盖四角，拧进木垫。齐平只取决于台阶深度，不受底壳和槽底影响。
3. **底壳**用 8 个卡扣挂在面盖下面，四周离槽壁 0.25，底部离槽底 0.3，不碰琴。
4. **主板和 USB 小板**拧在面盖背面的凸台上（主板 4 颗 M2，USB 小板 2 颗 M1.6）。插头插拔、按键的力直接传到面盖和台阶，不经过卡扣。
5. 面盖背面两条加强筋（1.2 × 3）增加刚性；三段弧形筋给扬声器定位。
6. **旋钮** Ø13，高出琴背 7.0；**按键帽**高出 0.5；**导光柱**顶面与面盖平。

## 和 1:1 面板模型的区别

- 面板布局、标签位置、喇叭网孔完全沿用模型。
- 开孔按量产件改：
  - 编码器孔 Ø7.6（模型 Ø7.3），螺套不用螺母，旋钮盖住孔；
  - 插座孔 Ø6.5（模型 Ø6.3）；
  - 按键孔 Ø5.6，配按键帽（模型是 Ø7.2 面板按钮）；
  - 指示灯改为 Ø3.1 导光柱，位置在两个按键之间（模型里预留的量产位置）；
  - USB-C 槽 9.4 × 3.6（模型 9.2 × 3.4），USB-C 座从槽里露出来。
- 刻字深 0.15（模型 0.6）；去掉模型上的分区线、电池虚线框和电池图标。
- 电池位置往琴头方向移 1 mm（X 106–136），让开琴尾端的螺钉木垫。

## 重新生成

需要 CadQuery 2.x（`pip install cadquery`）和 reportlab。

```bash
python3 build_enclosure.py      # 3D、STL、效果图、干涉检查（约 1.5 分钟）
python3 drawings.py             # 7 张图、合订本、关键尺寸清单、首件检验表（约 40 秒）
```

所有尺寸都在 `build_enclosure.py` 开头的参数区，改参数后两个脚本重跑即可。

## 坐标

和面板模型相同：X 沿琴身，X0 = 模块琴头端，X148 = 琴尾端；y 横向，y0 = G 弦侧边；Z0 = 琴背面 = 面盖顶面，Z 负值往琴里。模块 X0 距琴尾基准 258 mm（安装范围 u 110–258）。
